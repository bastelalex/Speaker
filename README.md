# Speaker · Waveguide-Werkstatt

Deutschsprachiges Entwicklungsprojekt zu Horn-Waveguides, Phaseplugs, Multicell/Polycell und Kompressionskammern mit LaVoce- und JBL-Treibern.

Die recherchierte Fachbroschüre (30 Seiten), der Designkatalog und der lokale Browser-Konfigurator werden in diesem Repository abgelegt. Alle Dimensionierungen sind Vorentwürfe; akustische Validierung erfolgt durch Simulation und Messung.
